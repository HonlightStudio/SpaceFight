# SpaceFight

SpaceFight is a 2D arcade-style space shooter game developed with Unity. Take control of your spaceship, dodge asteroids, and destroy enemy crafts in fast-paced, retro-style combat. Perfect for fans of classic shoot-'em-ups!

## Features

- Smooth 2D controls and fast gameplay
- Enemy AI with attack patterns
- Score tracking and UI system
- Health and damage system
- Sound effects
- Modular code structure for easy extension
